# Blog_Tere_em_Foco
O Blog Terê em Foco,  é um projeto de WEB FRONT END do curso de Ciência da Computação, formada por um grupo de 7 desenvolvedores, com o intuito de desenvolver de forma colaborativa um blog informativo sobre a cidade serrana do Rio de Janeiro. Com uma pegada de turismo, informações, notificações locais entre outros.
